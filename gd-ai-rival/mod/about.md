# AI Rival

Talk to an AI rival while you play. It watches your run and reacts to what happens:

- **Chat**: open the chat from the pause menu, the in-game chat button, or the keybind (<cy>T</c> by default on PC). The level pauses while you type.
- **Reactions**: the AI comments on deaths, new bests and completions. Ordinary deaths are rate limited so it doesn't talk over every attempt.
- **Memory**: the last few messages are remembered for the current level.
- **Level lock**: optionally only activate on specific level IDs.

This mod needs a proxy server to talk to the AI. Set its URL in the mod settings.
